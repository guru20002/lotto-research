# Lotto Research

מחקר סטטיסטי של תוצאות הלוטו בישראל. המערכת בודקת אם שיטות המבוססות על הגרלות עבר מצליחות לנבא תוצאות עתידיות טוב יותר מבחירה אקראית.

## הפעלה

1. הוסף למאגר קובץ נתונים בשם `Lotto.csv` (UTF-8; שורה אחת לכל הגרלה, שש עמודות של המספרים הראשיים ועוד עמודות אופציונליות).
2. היכנס ללשונית **Actions** ובחר **Lotto Research** ואז **Run workflow** להפעלה ידנית.
3. הדוח נשמר ב-`results/latest_report.json` וב-`results/latest_report.md`.

ה-workflow מתוזמן לריצה יומית. ייתכן עיכוב לפי עומסי GitHub Actions ומגבלות החשבון.

## זהירות מדעית

הגרלות לוטו אמורות להיות אקראיות. תדירויות עבר אינן כשלעצמן ראיה ליכולת חיזוי. הדוח משווה שיטה פשוטה לבחירה אקראית בבדיקת עבר ומדגיש שהממצאים אינם מבטיחים זכייה.
